GameNative AI Dev 1.2.1-ai-dev.12 – input live och samlad Codex-diagnostik

• Nytt: Quick Menu → Codex i spelet → Kontroll och input → Visa input live. En liten panel visar senaste Android-signaler, valda mappningar, spelarplatsens bryggskrivningar och native-signal, med ålder per steg. Kan minimeras och stoppas; avslutas senast efter fem minuter. Det korta 20-sekunderstestet finns kvar.
• Visa destinationer och API visar kontrollbryggans aktuella data per spelarplats. Observationen kan även visa äldre Wine-klienters XInput/DirectInput-begäran, rapporterat process-ID, lokal UDP-destination och sändningsfel.
• Analysera input med Codex använder ett samlat verktyg för konfiguration, kontroller, mappningar, brygga och observation. Agenten får samma underlag utan tre separata läsanrop. Ändringsförslag granskas och tillämpas som tidigare.
• Visningen läser bara. Ingen simulerad input, profiländring eller ändring av anslutningsflaggor. Inget skickas till modellen förrän du ber om analys med spelåtkomst. Inga skrivna texter registreras.

Data från appen visar inte säkert att PC-spelet har behandlat knappen. Sekvensökning och lyckad sändning är inga mottagningskvitton. Noll äldre Wine-klienter kan vara normalt när spelet använder SDL. Rapporterat process-ID är inte verifierat som spelets process.

Avsluta spelet och uppdatera via ⋮ → Appuppdateringar eller installera APK:n ovanpå AI Dev. Samma paket och signerare; versionskod 32. Avinstallera inte och rensa inte appdata. Rättningarna av kontrollbryggan i ai-dev.11 följer med.

231 tester godkända och APK-byggning lyckad. Avläsningarnas frånvaro av inputändringar, knappsläpp, tidsgränser och flödet från livepanel till granskat Codex-förslag är testade lokalt. UI granskat i båda skärmorienteringarna. De 32 native-biblioteken är oförändrade. Verklig kontrollrespons och JNI/Wine-överföring behöver provas på MagicPad; ingen fysisk Android-enhet var ansluten. Molnets svarstid är inte uppmätt.
